# 人物设计表（59 项三维人物小传问卷）

> 来源：实战影视模板通用化（空表零项目信息，可直接复用）。
>
> **两大用途：**
> 1. **剧本医生修复脚手架** —— `script-doctor.md` 诊断出人物类低分项（动机矛盾 / 工具人 / 降智）后，用这份问卷重做人物小传。59 项问完，人物就立住了。
> 2. **AI 生图人物视觉锚定素材单** —— 体貌层面若干项直接拼进 AI 分镜的风格前缀，保证全剧几十张生图人物一致（服装 / 发型 / 体格 / 佩戴 / 伤疤不漂移）。
>
> **使用规则：**
> - 每张表只填一个角色；主要角色全填，次要角色只填体貌层面 + 社会层面 1/4/9（家庭出身 / 婚姻 / 职业）。
> - 填完先给导演过目，认可后再进剧本与生图前缀（判断依据：人物设定 = 内容层决策，不跳过确认）。

## 一、体貌层面（20 项）—— 喂 AI 生图锚定 + 演员妆造

1. 年龄与性别
2. 肤色
3. 头发（发型、颜色）
4. 服装风格 ← **AI 分镜风格前缀必填项**
5. 牙齿（牙箍、颜色、镶牙）
6. 眼睛（颜色、有框眼镜、隐形眼镜）
7. 身高
8. 仪态
9. 体格
10. 健身习惯
11. 穿刺、纹身
12. 佩戴首饰
13. 伤疤、外形 ← **贯穿性特征，妆造连续性检查项**
14. 睡眠习惯
15. 卫生保健
16. 爱好
17. 谈吐 ← 台词写作参考（配合判断手册「读断测试」）
18. 行为习惯
19. 体质过敏反应 ← 剧情合理性 + 现场餐饮预案双用途
20. 擅长的运动/乐器 ← 动作戏 / 道具戏可行性依据

4. 沮丧/快乐
5. 焦虑的事
6. 娱乐方式
7. 最喜爱/讨厌的地方
8. 最喜爱的事情
9. 最讨厌的事情
10. 生日回忆
11. 悟性
12. 内向/外向
13. 癖好/嗜好

16. 完美主义
17. 习惯
18. 美梦/恶梦
19. 快乐的回忆
20. 过去的决定性时刻 ← **人物动机之根**（剧本医生「主线动机唯一」原则由此长出）

## 四、与技能其他文件的接口

| 接口 | 用法 |
|---|---|
| `script-doctor.md` | 人物类低分项 = 本问卷重填的切入点；「过去的决定性时刻」= 主线动机唯一性的答案来源 |
| `shots-schema.md` 生图 prompt | 人物前缀 = 体貌 4 + 3 + 9 + 12 + 13（服装风格/头发/体格/首饰/伤疤）组合，导演确认后写死 |
| `build_schedule.py` 妆造连续性 | 体貌 13（伤疤/外形）必须与妆造状态区间自洽，否则穿帮 |
| `taste-and-judgment.md` | 体貌 17（谈吐）= 台词身份×处境双检的性格依据 |
