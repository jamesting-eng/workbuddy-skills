# 分镜中间数据 shots.json 与生图 prompt 模板

## shots.json 结构（四消费方共用：分镜表 xlsx / AI 生图 / AI 分镜板 PDF / 顺场表）

```json
[
  {
    "no": 12,                    // 镜号，1 起连续，全剧唯一
    "scene": "第三场\n第二幕《冲突》",  // 场次（含换行的原样保留，消费方自行 norm）
    "size": "中景",               // 景别：大远景/远景/全景/中景/中近景/近景/特写/大特写
    "move": "快切",               // 运镜：固定/慢推/缓推/跟拍/手持跟拍/环绕/正反打/定格/慢镜头/快切/特效/主观
    "pic": "〖画面〗男主把女主拽回靠墙对峙",  // 画面内容（〖〗=心动镜头标记）
    "dlg": "男主（低沉）：你这一走，就别再回头！\n女主（惊愕）：是你？",  // 台词，多句用 \n；无台词留空
    "note": "【第2集切点】门「砰」带上",   // 备注：含「第N集切点」「心动镜头」字样会被 PDF 组装器识别打标
    "dur": "4s"                  // 时长（秒+s 后缀），合计=全剧时长
  }
]
```

生成方式：从剧本逐幕拆镜时同步产出（每镜 = 剧本里一个编号镜头），openpyxl 写分镜表 xlsx 时复刻用户提供的模板格式（宋体、行高 110-140、场次列纵向合并）。

## AI 生图 prompt 模板（ImageGen，1536x1024，quality=medium）

**固定风格前缀**（保证全部镜图风格统一）：

> 黑白手绘电影分镜插画，铅笔素描加淡墨晕染质感，细腻排线阴影，高对比戏剧光影，无任何文字无水印。

**逐镜 prompt 结构**：`第0NN镜：` + 固定前缀 + `。` + 景别声明 + 人物（服装/发型具体化，主角全文一致）+ 动作/构图 + 光影/情绪。

要点：
- **景别必须写死在 prompt 里**：特写=「面部充满整个画面，仅头部与少量肩部入画」；大远景=「人物很小仅占画面高度约五分之一，大面积留白」——这是景别控制的关键，AI 默认会画成中景
- 每镜开头带 `第0NN镜：` 前缀，生成后按前缀统一改名 `shot_NN.png` 并校验数量
- **先出 3 张样张**（特写/中景/远景各一）给用户确认风格，再批量
- 后期镜（片头/片名/片尾）不生图，组装时黑底说明格
- 成本：约 6 积分/张，先向用户报总预算

**以 `references/hollywood-format.md`（定稿实测反推）为唯一事实源**，此处不再重复列表——参数写两处必然漂移（实测教训：速记表与定稿实测曾出现右缩进 105pt/60pt 两说）。edsdk 的 indent / spacing / jc 三类属性互斥不能同包，分多次 doc_modify_paragraph 调用；twips 换算：pt × 20。
