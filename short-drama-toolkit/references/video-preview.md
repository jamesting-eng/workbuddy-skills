# 分镜动态预览视频（生成视频）

## 触发

导演 / 团队希望把静态分镜图变成"会动的预览"，用于开拍前对齐运镜节奏、镜头时长、转场感受。它是**拍摄前的效果预览**，不是成片。

## ⚠️ 算力 / 积分友情提醒（强制）

> 当用户选择"生成视频"时，**必须先口头告知并征得明确确认，不得静默启动**。

- 本操作对**每一张**分镜图调用图生视频（image-to-video）模型。单镜通常 3–17 秒动态，全剧数十镜累计：
  - **耗时**：数十分钟级（按镜数线性增长；可并行但各镜独立计费）
  - **积分**：可观（图生视频比生图贵，按镜数 × 时长计）
- **如果静态分镜图（AI 分镜 PDF）已经足以表达拍摄意图，可以不开生成视频。** 先把分镜图给导演 / 团队看，确认确实需要"动起来"再生成。
- 必须等用户明确回："知道耗时和积分，仍要生成" 后才启动批量；逐镜先出 **3 张样张**确认风格与人物一致性，再全量。

## 工作流

### 输入

- `shots.json`（第 3 步产物，含每镜 `dur` 时长、`move` 运镜、画面描述）
- `shot_NN.png` 分镜图（第 4 步产物，已去运镜记号）

### 1. 逐镜生视频

- 以分镜图为**首帧**，调用图生视频（image-to-video，如 miora VideoGen / 平台同类能力）。
- motion prompt = 运镜(`move`) + 画面描述，例如「镜头缓慢推近，人物保持静止凝视」。运镜幅度写"轻微 / 缓慢"，过大易崩坏。
- 风格保持：prompt 里带与第 4 步生图一致的**固定风格前缀**，保证图→视频风格连续、人物一致。
- 运镜记号清除：若分镜图角落还有蓝 / 红运镜箭头记号，先用邻域修复清除再喂生视频（否则模型可能把记号当画面元素，或裁掉画面）。

### 2. 时长归一

- 按 `shots.json` 的 `dur` 统一每镜时长：
  - 表时长 ≤ 视频时长 → 直接裁剪
  - 表时长 > 视频时长 → 慢放（≤2x）后尾帧 hold（`tpad=clone`）补齐
- 统一 fps / 分辨率（建议 24fps，与分镜画幅一致；如 1956×1056 或 1536×1024 等比放大）。

### 3. 后期镜处理

- 片头闪前：用结尾某镜的"消散 / 拉远"段**反向**（`reverse`）截取，制造梦境→现实切入。
- 片名卡 / 片尾字幕卡：黑底白字 PNG，`-loop 1` 生成带淡入淡出的静帧视频。

### 4. 拼接

- concat demuxer 按镜号顺序拼接：闪前段 → 标题卡 → 真实镜 → 尾卡若干。

### 5. 音频策略（重要，避免"鬼片 BGM"）

- **默认静音交付（`-an`）**：代码合成的 BGM（所谓古风五声 / 随机钢琴）极易廉价、瘆人。除非用户自备**正版授权 BGM 音轨**，否则不要自动合成 BGM。
- 若需音效（脚步、翻书、环境音等）：用**独立的合成 / 授权音效素材**单独叠加，且与 BGM 分轨，便于日后单独保留或删除。
- 只有用户明确要 BGM **且**提供了音轨文件，才 mux 进成片；交付前确认用户对音轨满意。
- 复用 `scripts/make_video_preview.py`：传 `--bgm <file>` 才混流 BGM，不传则静音。

## 交付物

- `片名_动态分镜预览.mp4`（默认静音，总时长 = 各镜 dur 之和 + 字幕卡时长）
- 配套 `shots_clean/`（已去记号的分镜图）、`clips/`（逐镜视频片段）、`segs/`（归一化段，便于单独调整某镜）

## 复盘要点

- 逐镜视频生成是算力大头，务必先样张（3 镜）确认风格与人物一致性，再批量。
- 人物一致性靠首帧 + 风格前缀锚定；运镜幅度过大易崩坏，prompt 里写"轻微 / 缓慢"。
- 音频是体验放大器也是翻车点：拿不准就静音，比一段瘆人 BGM 安全得多。
