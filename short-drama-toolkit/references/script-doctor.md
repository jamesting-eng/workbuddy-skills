# 剧本医生评估框架（Script Doctor Checklist）

> 来源：用户方自研 AI 剧本医生的评估模板，经真实电影剧本评估实战验证（样本：一部百页级电影剧本初稿获不及格评分、定性"结构性问题突出"，诊断意见精准命中动机矛盾/反派缺失/功能性人物冗余三处硬伤）。
> **与判断手册的分工**：本框架管**改前诊断**（整体质量定位、问题清单），`taste-and-judgment.md` 管**改中执行**（逐条落地判断）。先诊断、后动笔，不许拿到剧本就开改。

## 使用时机

1. **新剧本进入改稿流程前**（标准动作）：跑完整评估 → 出诊断报告（总评 + 分项 + 具体修改意见）→ 问题清单经用户确认 → 带着诊断进 SOP 第 1 步改稿
2. **每轮改稿结束后**（复评）：只重跑上一轮的问题项，验证是否真修复
3. **新剧本立项评估**（选做）：全跑 + 市场维度 + 政策风险

## 评估报告结构

1. **元信息头**：片名 / 编剧 / 类型 / 第几稿 / 剧本页数 / 完成时间 + Logline（一句话故事）+ Synopsis（梗概）——先复述再诊断，确认对剧本的理解无偏差
2. **总评**：定性结论（如"可立项 / 需打磨后可拍 / 问题较大建议不采纳"）+ 总分（100 分制）
3. **分项评估表**：下面 23 条，四级评分（棒 / 很好 / 一般 / 此不适用）
4. **具体修改意见**：七维展开（见末节）——**打分只是定位，修改意见才是交付物**

## 评估清单（5 大类 23 条，四级评分）

### 概念 Concept
1. 新鲜和独特性（original and unique）
2. 故事有明确的"钩子"
3. 强烈的节奏控制（事件频率和间隔）

### 人物 Characters
4. 主人公有明确的内在和外在目标
5. 有强大的反对力量和主人公对抗
6. 主人公的追求让你看 90 分钟而不厌（短剧适配：换算为"每集都有追看理由、钩子不断"）
7. 主人公有明显的弧线（变化）
8. 辅助人物提升故事的总体价值——**反例甄别**：主持人/记者等功能性人物对剧情推动不大 → 建议删除
9. 主人公是三维人物并且有缺陷
10. 不同人物有不同的价值观
11. 人物有丰富完整的前史（back-stories）
12. 大反派有明确的目标和动机（**重点核查项**：无反派/对手动机不明 = 冲突驱动力缺失）

### 台词 Dialogue
13. 每个人物的台词都有自己的个性（与判断手册 2.2"身份×处境双检"互查）

### 结构 Structure
14. 辅助故事和主线故事相辅相成
15. 铺垫明确为影片建立了色调和目的
16. 每一场戏都具有功能 / 支持剧情发展
17. 每场戏的过渡都恰到好处
18. 影片大高潮值得等待（短剧适配：换算为"每集结尾留人 + 终集兑现"）
19. 激励事件为故事提供了足够驱动力
20. 戏剧张力的建立和释放张弛有度
21. 人物处置符合晚进早出原则

### 影像 / 视觉风格 Visual
22. 拥有视觉上抓人的开篇 / 高调的开头
23. 剧本为视觉惊艳提供了空间和可能

## 具体修改意见（诊断报告正文，七维展开）

1. **故事**：动机链核查——主人公的核心动机全剧只能有一个主线（实战教训：参赛动机"证明自己"与"赚钱救父"前后矛盾被判硬伤；喜欢上 doing 的理由必须让观众信服）
2. **人物**：主角逐个重做人物小传；功能性人物删除
3. **结构**：结构性问题优先级最高（实战样本中"问题较大"的主因即结构）——本框架判出结构低分时，改稿顺序 = 先结构后台词
4. **主题**：主题是否被剧情自然承载（不是口号）
5. **市场**：观众画像（性别占比 / 年龄层 / 城市层级）、受众宽窄、破圈难度——短剧同样适用，且平台标签维度更细
6. **政策风险**：题材合规性初筛
7. **对标片**：列 2-3 部同类型成功片，供结构/人物深挖时参考

## 短剧适配注意

- 电影百页级体量 ≈ 微短剧整季体量的几十倍，条目 6/18 的"90 分钟/大高潮"在短剧里换算为**集级钩子**与**每集结尾留人**
- 台词区在短剧里权重更高（短剧靠台词撑情绪），可加测：危机台词做减法（见判断手册 2.2）
- 23 条全跑约需通读剧本 2 遍：第 1 遍整体感受打分，第 2 遍逐条找证据——**打分必须带证据行**（"一般"要有具体段落支撑），禁止凭印象
